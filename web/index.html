Отчёты посещаемости

Суточный, недельный, месячный отчёт или произвольный диапазон дат. В отчёт входят первый приход, последний уход и состояние пользователя на конец каждого дня.

Выберите период и нажмите «Сформировать».

Расширенный отчёт по пользователям

Показывает каждый вход и каждый выход выбранного пользователя, нескольких пользователей или всех сотрудников за указанный период. События идут в хронологическом порядке с картой и контроллером.

Выберите период и пользователей. В отчёт попадут все входы и выходы.

Автоматическая отправка по расписанию

Используется Bot Token и Chat ID из настроек Telegram. Автоматические отчёты отправляются как текстовый файл.

Что отправляется автоматически: суточный — предыдущие завершённые сутки; недельный — предыдущая календарная неделя (Пн–Вс); месячный — предыдущий календарный месяц.

Контроллеры UNEX 721

Состояние и действия с аппаратными контроллерами.

Кнопка «Обновить» выполняет реальный безопасный опрос 24H Read RTC и показывает Reader ID, который сообщил сам контроллер. Изменение ID выполняется официальной командой 80H Set Node ID, затем новый ID обязательно проверяется повторным 24H. Допустимый диапазон: 1..254.

«Вычитать посещаемость» принудительно читает накопленный FIFO командой 25H до пустого ответа. Дата и время берутся из самой записи контроллера; запись удаляется из FIFO через 37H только после успешного сохранения в БД.

«Отключить пропуск любой карты» изменяет только EEPROM 0x0016 bit 0x20 и проверяет запись повторным 12H. Пользователи при этом не изменяются.

Поиск карты в EEPROM UNEX 721

Диагностическое чтение командой 12H Read EEPROM. Ничего в контроллер не записывается. Поиск проверяет представления серии/номера и, если указаны User Address, сначала читает их через 87H и ищет в EEPROM точную compact 8B RAW-запись. Ничего не записывается.

Выгрузка пользователей в контроллеры

Выберите всех или отдельных пользователей и контроллеры назначения. Запись выполняется официальной H-series командой 83H Set User Data; после ACK программа обязательно читает тот же адрес через 87H и сравнивает 8 байт. При выборе «Все пользователи» выполняется полная синхронизация: сначала отключается глобальный режим H-series «любая карта» (EEPROM 0x16 / 24*, снимается bit 0x20 с сохранением остальных опций), затем все отсутствующие адреса 0..1023 принудительно записываются нулями через 83H и проверяются 87H; после этого нужные пользователи записываются и также проверяются через 87H.

Удаление пользователей

Можно удалить выбранных или всех пользователей из программы, из выбранных/всех контроллеров, либо одновременно из обоих мест.

Безопасное комбинированное удаление: при выборе «из системы и контроллеров» локальная карточка пользователя удаляется только после подтверждённого удаления этого пользователя из каждого выбранного контроллера. При ошибке связи пользователь остаётся в системе.
